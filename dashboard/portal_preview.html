One-time setup on your own computer

1. Create your own OpenAI API key using the provider's official developer site and set a small account spending limit.

2. Set two local environment variables: OPENAI_API_KEY to your secret key, and NEXUS_ENABLE_LLM_RESEARCH to 1. Restart Nexus after updating environment settings.

3. Select a public market, review the exact displayed public-data preview and its SHA-256 hash, then separately choose Send One Research Request (May Cost Money). If the public dataset is not eligible or changes, the request is blocked. No account data, orders or automatic billable requests are authorized.

Never paste your API key into this screen, code repositories, or chat. Configuration alone does not prove provider connectivity. The app's request cap is five attempts per process; this is NOT a guarantee of a dollar spending limit.
